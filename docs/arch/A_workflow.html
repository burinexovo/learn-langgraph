節點分工（顏色 = 該用哪種實作）

  • 完整 Claude Code SDK/CLI（align_requirements, code_agent）
  • 窄範圍 LLM + tool（plan_slices, test_agent, review_agent, synthesize_verdict）
  • 純 Python，不問 LLM（分派、合併、把關）
  • 人工（human_checkpoint，唯一需要人的地方）

跟 A2（blackboard 版）的關鍵差異

  • 用固定波次（wave）分派：同波不重疊才平行，波與波之間依序跑
  • code_agent 是 LangGraph 自己用 Send 管理的平行分支，不是外部獨立 process
