$ claude --resume 

claude CLI 能不能被當成 subprocess 驅動，接進 LangGraph 的 code_agent 節點？三個依序驗證的最小實驗。

日期 2026-09-11 環境 scratchpad（未設 ANTHROPIC_API_KEY） 來源 labs/
  • 免 API key — 靠現有訂閱登入就能跑，不用另外申請
  • resume 跨 process 有效 — session_id 可直接存進 LangGraph state，下一輪接續
  • 真跑過 LangGraph demo — 兩輪呼叫都正確接住上下文，不是塞更多文字硬湊

背景

Python Claude Agent SDK 強制走獨立計費的 ANTHROPIC_API_KEY，不能沿用個人訂閱登入。Alan 提到 claude CLI 接 Discord 能跑，於是驗證 CLI 這條路技術上通不通。

三個測試依序驗證、彼此有依賴：認證 → session resume 跨 process → 自訂 session_id。全程純文字問答，排除工具權限這個變因。

TEST 1 — 免 API key 能不能跑

PASS 
$ claude -p "Reply with exactly the single word: PONG" --output-format json
> result: "PONG"
> session_id: af985dea-3d1b-4f97-a199-fc1ab573876d

免 API key，靠現有訂閱登入即可。

TEST 2 — resume 能不能跨 process

PASS 
$ claude -p "我上一則訊息要求你回覆的字是什麼？" \
    --output-format json --resume af985dea-3d1b-...
> result: "PONG"
> session_id: 維持不變

跨 process 有效，session_id 可直接存進 LangGraph state。

TEST 3 — 能不能自訂 session_id

PASS 
$ MYID=$(python3 -c "import uuid; print(uuid.uuid4())")
$ claude -p "Remember this secret code: BLUE-42" --session-id $MYID
$ claude -p "What was the secret code?" --resume $MYID
> result: "BLUE-42"

呼叫前可先 uuid.uuid4() 產生 ID 寫進 state，不用等回應。
